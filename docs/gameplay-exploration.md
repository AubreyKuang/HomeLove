# 像素小屋 · HomeLove的玩法探索

沿用游戏内时间、来访时段和居民偏好。用现有约会地点验证玩家会不会根据当天安排改变选择。

## 已实现的试玩版本

| 试玩 ID | 玩家目标和反复选择 | 状态、进展与代价 | 依据与最小试玩 |
| --- | --- | --- | --- |
| HL-01a（HL-01；地点影响占用时段并预告结束时间） | 今天还想做什么？看对象偏好和结束时间，选地方或改天再约。 | 实时日程 · 选择地点并预支时间 · 居民班次继续变化 · 关系仍按地点偏好推进 · 长约会可能错过当天的另一件事。 | 源码已有固定来访时段和地点偏好。比如江屿偏爱池塘，白夜偏爱星空，最短的地点不总是最合口味。未知：是否有人在白天也会为了别的安排主动换地点？拿一个今天还要交委托的存档，比较有无结束时间预览时的选择。 |

人工试玩待进行。下面的判断来自源码和规则推演。

## 探索过的方向

| ID | 读取的状态 → 反复做的选择 | 进展、代价与熟练策略 | 初筛 |
| --- | --- | --- | --- |
| HL-01 | 时刻和对象偏好 → 选近处短约会或喜欢的长约会 | 推进关系 / 耗时与错过其他事 / 先算今天剩余时段 | 留下，改成 HL-01a |
| HL-02 | 来信和种田进度 → 现在交替代品或等想送的收成 | 完成委托 / 延迟且可能错过 / 先看成熟和来访时间 | 待测；需要物品改变结果才超出现有备选交付 |
| HL-03 | 双方日程和地点 → 约明天见或即刻出发 | 兑现约定 / 承诺占用未来时段 / 避开村里活动 | 待测；要验证守约是否变成打卡 |
| HL-04 | 菜地、背包与饱腹 → 收成留作晚餐或做礼物 | 饱腹或培养关系 / 同一份资源只能用一次 / 按当天需求分配 | 待测；现有机制已有一部分 |
