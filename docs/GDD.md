## 游戏概述

玩家在小屋与村镇之间生活，按居民的时间安排见面、送礼和一起活动。关系可以走向约会、告白和同居，首次共同经历会留在日记与画册。玩家也可以只探索村镇、养宠或收集穿搭。

- 俯视像素生活与恋爱模拟 · 网页 · 键鼠与触屏 · JavaScript / Canvas / Web Audio
- [ASSUMPTION] 目标玩家为喜欢角色故事、轻量采集和自由日程的玩家。

## 设计支柱

- 找人的地点和时段能影响一天的安排。
- 关系升级来自双方一起经历过的事。
- 支线可以改天去，错过一次仍能继续生活。

## 核心循环

照顾状态并看时段 → 选一个地点和居民 → 聊天、送礼或安排活动 → 留下关系与回忆 → 回家过夜再规划。
