# 四款游戏的 UI 与交互改进

第一轮以 HomeLove 为样板。先用约 390 px 宽的手机竖屏走通首日流程，再用桌面键鼠复核。样板验收后，将同样的试玩方法用于 DollHouse、Dreamer 和 Forbidden-City。

各游戏保留自己的界面风格。跨游戏复用的验收问题是关闭面板后能否继续刚才的操作、玩家能否主动取消操作，以及受阻时能否看懂原因和下一步。

## HomeLove 样板

### 首日提示

- 进入小屋后，轻提示「出门到院子里」。走到院子且顾言在附近时，再提示「去和顾言打个招呼」。
- 玩家可以随手收起提示，也可以直接去钓鱼、换装或逛村。完成问候或主动收起后，本局不再弹出首日提示。
- 顾言离开后撤下指向他的提示。玩家可以继续探索，想找顾言或其他居民时，再主动打开地图查看活动时段。

### 地图路线

- 玩家从地图选择目的地后，角色沿路线行走。点「取消路线」时角色停在原地，马上可以手动走动。
- 按方向键直接接管移动。点击另一处可到达的地面时，角色改走新目标。
- 行走中可打开地图查时段。角色停在原地，关图后继续前往原来的地点。地图上的「正在这里」按当前排班与角色位置显示。

### 同钓邀约

日记顶部按日期显示已经约好的事。约会和有时段的重访临近时，时钟旁会出现「今天」入口。日记发起的赴约路线也显示目的地并支持就地取消。

白夜收到月光鱼后，日记会记下邀约日期和 19:00–23:30 的时段，并提示在院子等他。精力不足时，邀约会写明需要 5 点精力。抛竿后可以点「收起鱼竿」，同钓重抛不可用时会显示是精力不足还是已过时段。

### 试玩验收

| 场景 | 操作 | 预期 |
| --- | --- | --- |
| 正常问候 | 新开一局，出门，和顾言说话 | 提示随场景更新。问候完成后收起，地图仍可正常使用。 |
| 主动略过 | 在屋里收起提示，换装后出门 | 操作照常，出门后提示不再出现。 |
| 错过顾言 | 在其他地方逛到顾言离开，再打开地图 | 顾言的箭头和文字退场。玩家能在地图中查看活动时段。 |
| 取消或改道 | 选一个较远的目的地，分别用取消按钮、方向键和点地面中断 | 三种操作分别对应就地停下、手动接管、改走新目标。旧路线标记同步消失。 |
| 返回游戏 | 打开地图，再关闭并继续移动 | 手机上触控可以立刻使用。桌面上键盘焦点回到游戏，方向键可以立刻走动。 |

手机竖屏重点检查提示、路线取消按钮和触控区是否互相遮挡。桌面复核键盘操作和焦点。提示和路线文案沿用现有的中文、英文、日文三套文本。

本轮在 Chrome 的 390 × 844 触屏模拟和 1280 × 800 桌面视口验证了表中五条路径。手机视口还检查了三语提示的宽度、关闭按钮的点击区域和地图地点列表的滚动。正式版和测试版均已打开验证，真实手机验收待做。

## 后续三款的试玩路径

- DollHouse：选中住户，安排使用家具，看见住户行动。也尝试家具走不到或住户太忙的情况。
- Dreamer：第一次滑行时完成转向和刹停，然后继续观景。
- Forbidden-City：登基后做一次会消耗精力的行动，再推进月份。检查当前能做的事、行动成本和推进月份的提示。
