## 为 TapTap 做的改动

- **存档回退**（`cottage-storage.js`）：存档、语言和声音开关依次试 `tap.setStorageSync` → localStorage，每一种都先写入、读回一致才用。`tap` 存储按 20 万字符分块，单个 key 不超过 1MB；先写分块、最后写索引，写到一半失败时旧存档仍可读。都不能用时照样可以玩，按下「进入小屋」后提示一次「当前环境无法存档，本次仍可游玩」。第一次在 TapTap 里打开时，同一 WebView 里浏览器版留下的存档会搬过去一次。
  - IndexedDB 没有列入：游戏在脚本加载时同步读档（`SaveManager.load`），IndexedDB 只能异步读取。
  - 测试版 `dev.html` 仍用独立的 `homelove-save-dev`，正式版用 `homelove-save-v1`，三种存储里都互不影响。
- **本地字体**（`fonts/`）：不再从 fonts.googleapis.com 加载。四款字体都来自 Google Fonts 官方仓库 [google/fonts](https://github.com/google/fonts)（commit `6ebe737e`，`ofl/` 目录），SIL Open Font License 1.1，无保留字体名，授权文件放在同目录。中文、日文字体用 `scripts/subset-fonts.py`（fonttools）按游戏三种语言实际出现的字做子集：

  | 字体 | 用途 | 原始 | 打包 |
  | --- | --- | --- | --- |
  | ZCOOL KuaiLe | 中文标题、人名 | 1.5MB TTF | 167KB WOFF2，1585 字 |
  | DotGothic16 | 日文标题、人名 | 2.0MB TTF | 113KB WOFF2，1571 字 |
  | Pixelify Sans | 英文标题、人名 | 79KB TTF | 21KB WOFF2（完整，可变字重） |
  | Silkscreen | 按键提示、A 键 | 32KB TTF | 8KB WOFF2（完整） |

  三种语言文本里只有 emoji 不在这些字体里（交给系统 emoji 字体），另有日文的「屿」不在 DotGothic16 里，会用系统日文字体补上。以后 `lang/*.js` 加了新字，需要重跑 `python3 scripts/subset-fonts.py --src <原始字体目录>`。
- **不联网**：打包脚本会检查包里没有 `http(s)://`、`fetch`、`XMLHttpRequest` 等联网写法；浏览器测试也确认运行时没有任何请求离开本地服务器。
- **TapTap 宿主**（`js/taptap.js`）：只检测全局 `tap`，不调用 `tap.login`，不联网。在 TapTap 内：切到后台时（`tap.onHide`）立即存档；导出存档、保存明信片 / 纪念卡等下载文件的按钮不显示（WebView 没有下载目录）。

《像素小屋·心动日常》是一款像素风的生活模拟小游戏：过日子、换装、谈恋爱。

你住在村口的一间小屋里。饿了做饭，困了睡觉，在院子里种草莓、摘花，去池塘边钓鱼，到小路边的领养站接一只小猫、小狗、小鸟或小兔回家。时间会自己往前走，春夏秋冬轮流来；冬天的第一场雪落下，池塘结了冰，还可以约人去冰钓。

一天里有五位居民轮流来院子：清晨的咖啡师顾言、上午的花店店员林小满、中午的篮球少年陆星野、傍晚的吉他手江屿、深夜的画星人白夜。每个人喜欢的穿搭、礼物、聊天方式和约会地点都不一样，多试几次，把发现记在日记的「攻略笔记」里。好感够了可以约会、告白，甚至搬来一起住；和别人走得太近，恋人也会吃醋。

衣柜里有各种衣服、发型和颜色，可以随意试穿、收藏搭配，带 ♥ 的是有人喜欢的。周末村里有集市和小活动，偶尔停电的夜里，大家会提着灯出门。一起经历过的事会收进画册，随时翻回来看。

支持中文、English、日本語。单机游玩，不用联网，没有内购，没有广告，存档只保存在本机。

这是我一个人做的小游戏。一开始只想做一间能随便换衣服的像素小屋，后来院子里慢慢住进了五位邻居：早起开店的咖啡师、爱花的店员、打球的少年、弹吉他的人，还有半夜画星星的人。游戏里的像素画面都是用代码一点点画出来的。
